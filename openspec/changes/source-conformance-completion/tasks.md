## Commands

Use Bun/Nx from the repository root. Focused runs use the owning source's test target with its runner filter where supported, explicitly producing a partial report. Full certification commands are `bunx nx run store-sqlite:test:conformance` and `bunx nx run store-memory:test:conformance`; infrastructure is `bunx nx run conformance:test`. Each target must be created before its command is claimed to work. Run each project's lint/typecheck and normal test target after its slice; run `core:test:portable` after history composition changes. On h2puni the final workspace command is `bin/h2puni-gate.sh`; use the canonical heavy lock for expensive source suites and never race the accepted R10 timing lane. Parent validates `bunx openspec validate source-conformance-completion --strict` and `bunx openspec validate --all --json` for this design delivery.
